- **Бучинський Денис** (Розділ 3: Дослідження впливу розподілу символів на ентропію; Розділ 4: Дослідження залежностей та періодичності)

---

### Структура проекту:
- `data/` — вхідний корпус тексту (Л. Толстой «Війна і мир», томи 1-2, > 1.6 МБ) та згенеровані нормалізовані тексти:
  - `raw_text.txt` — первинний текст (> 1.6 МБ);
  - `text_with_spaces.txt` — текст з пробілами (33 символи алфавіту);
  - `text_without_spaces.txt` — текст без пробілів (32 символи алфавіту);
- `preprocess.py` — правила та реалізація попередньої обробки тексту;
- `entropy_calc.py` — розрахунок частот літер, перетинних і неперетинних біграм, $H_1$, $H_2$;
- `experiments.py` — експерименти з послідовностями А, Б, В (Розділ 3) та Г, Д (Розділ 4);
- `shannon_entropy.py` — обчислення меж Шеннона за даними 50 дослідів CoolPinkProgram та надлишковості $R$;
- `main.py` — комплексний запуск усіх обчислень та виведення зведених таблиць;
- `results/` — експортовані таблиці частот у форматі CSV (`letters_*.csv`, `bigrams_*.csv`).

---

### Інструкція з запуску:

1. Запуск повного циклу аналізу:
```bash
python main.py
```

2. Запуск окремих модулів:
```bash
python preprocess.py
python entropy_calc.py
python experiments.py
python shannon_entropy.py
```
