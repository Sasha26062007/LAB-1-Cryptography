# Комп'ютерний практикум №1
## Експериментальна оцінка ентропії на символ джерела відкритого тексту

Репозиторій лабораторної роботи з дисципліни **«Криптографія»**.

### Склад бригади (група ФБ-44):
* **Панайотов Олександр** (Тімлід):
  - Розділ 1: Підготовка та нормалізація великого корпусу тексту (>1 МБ).
  - Розділ 2: Розрахунок ентропії монограм ($H_1$) та біграм ($H_2$: перетинні та неперетинні), визначення топ-5 символів і біграм.
* **Бучинський Денис**:
  - Розділ 3: Дослідження впливу розподілу символів на ентропію (послідовності А, Б, В).
  - Розділ 4: Дослідження залежностей між символами та виявлення періодичності (послідовності Г і Д).
* **Костенко Володимир**:
  - Розділ 5: Експериментальна оцінка умовної ентропії за методом Шеннона в CoolPinkProgram (по 50 дослідів для $n = 10, 20, 30$).
  - Розділ 6: Розрахунок коефіцієнтів надлишковості $R$ та зведення підсумкових таблиць.

### Структура проекту:

```text
cp1/ФБ44_Панайотов_Бучинський_Костенко/
├── data/
│   ├── raw_text.txt             <- Вхідний текст Л. Толстого «Війна і мир» (1.62 млн симв., > 2.7 МБ)
│   ├── text_with_spaces.txt     <- Нормалізований текст із пробілом (m = 33, 1.34 млн симв.)
│   └── text_without_spaces.txt  <- Нормалізований текст без пробілів (m = 32, 1.12 млн симв.)
├── results/
│   ├── letters_with_spaces.csv
│   ├── letters_without_spaces.csv
│   ├── bigrams_with_spaces_overlapping.csv
│   ├── bigrams_with_spaces_non_overlapping.csv
│   ├── bigrams_without_spaces_overlapping.csv
│   ├── bigrams_without_spaces_non_overlapping.csv
│   ├── shannon_guessing_results.csv
│   └── summary_entropy_table.csv
├── preprocess.py                <- Модуль очищення та попередньої обробки тексту
├── entropy_calc.py             <- Розрахунок частот і ентропій H1 та H2
├── experiments.py              <- Дослідження штучних джерел та періодичності (А, Б, В, Г, Д)
├── shannon_entropy.py          <- Оцінка меж Шеннона (F_L, F_R) та надлишковості R
└── main.py                     <- Головний скрипт повного циклу аналізу
```
